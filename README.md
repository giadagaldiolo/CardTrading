# Card Trading Web App

## Description
A web-based card trading application built with **Spring Boot**, **Thymeleaf**, and **Bootstrap**.  
The project allows users to browse, manage, and trade collectible cards in an interactive and dynamic web environment.

---

## Overview
This project was developed for educational purposes as part of a web development course.  
It focuses on the integration of **Spring Boot for backend logic**, **Thymeleaf for dynamic HTML templates**, and **Bootstrap** for a responsive and modern UI.

---

## Main Features
- 🏠 **Home Page**
  - Displays featured cards and quick navigation options.

- 🃏 **Card Management**
  - View detailed information for each card.
  - Create, edit, and delete cards.
  - Each card includes name, type, description, image, and price.

- 💰 **User Accounts**
  - Registration and login system with role-based access (user/admin).
  - Secure authentication and authorization via Spring Security.

- 🛒 **Wishlist & Cart**
  - Add cards to a personal wishlist or shopping cart before purchase.

- 🎨 **Responsive Design**
  - Fully styled using **Bootstrap**, ensuring a consistent look across all devices.

---

## Technical Details
- **Backend:** Spring Boot  
- **Frontend:** Thymeleaf + Bootstrap
- **Database:** MySQL (via Spring Data JPA)  
- **Security:** Spring Security (authentication & authorization)  
- **Build Tool:** Maven  
- **Version Control:** Git
